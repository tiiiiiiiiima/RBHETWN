# Проверка самостоятельной сборки на Windows

Распакуйте пакет целиком в новую папку. Рядом должны лежать
BakuganPrototype-Windows.exe и BakuganPrototype-Windows.pck.
Для обычной игры достаточно открыть EXE. Нужен Windows x64 и OpenGL 3.3.

Для автоматической проверки откройте PowerShell в этой папке и выполните:

```powershell
.\BakuganPrototype-Windows.exe --script res://scripts/release_verifier.gd -- --verify-release
```

Команда запускает встроенный GDScript; отдельные CMD/PS1-файлы и Python
не нужны. Проверка работает без интернета. Основной профиль не читается
и не перезаписывается: тесты используют diagnostics/0.22 внутри
пользовательской папки игры в %APPDATA%/Godot/app_userdata.

Сценарий последовательно запускает три процесса: быстрый матч до трёх карт,
кампанию с сохранением движущейся сферы и продолжение кампании. Обычно это
занимает несколько минут. На каждый полный матч отводится 210 секунд;
тайм-аут считается неудачей. Выводы находятся в diagnostics/0.22/reports:
quick.json, save.json, resume.json, summary.json, журналы и снимки.
После перезапуска сверяется точный бинарный хеш позиции, скорости, времени,
счёта, главы, генератора и собранных предметов.

Успех требует passed=true в summary.json и во всех трёх стадиях. Поле os
фиксирует среду исполнения. Отчёт Linux не считается результатом Windows. Память процесса
читается через штатный Get-Process в конце стадии; недоступный счётчик
помечается, настройки безопасности не изменяются.
Сценарий использует программно введённые события мыши/клавиш; физический
геймпад, драйверы звука и субъективное качество управления требуют
отдельной проверки на устройстве. Для ручного прогона: новый профиль,
обучение, быстрый матч, кампания, пауза во время броска/мини-игры, закрытие
окна, продолжение, смена разрешения, отключение геймпада и повторный матч.

Нативный Windows-прогон 0.22 завершён на GitHub Actions, Microsoft Windows
10.0.26100: полный быстрый матч 3:1, сохранение летящей сферы и продолжение
кампании 3:0 в новом процессе. Точный бинарный хеш состояния совпал;
результаты и награды сохранены. Дополнительно прошли 3098 ресурсов,
13280 утверждений и 69 проверок исправлений.

На сервере применяется ANGLE/WARP через командную строку. qa/windows_release_verifier.gd
повторяет упакованный сценарий, меняя только драйвер и путь запуска дочерних
процессов. Все игровые ресурсы, код правил и физика берутся из неизменённого
PCK выпуска; дополнительные графические DLL в архив не добавлялись.
Первый запуск с native OpenGL/Mesa не создал окно на сервере; его тайм-аут
не засчитан как успешный матч. Успешный прогон: [Windows 0.22 verification](https://github.com/tiiiiiiiiima/RBHETWN/actions/runs/38275378205).
Отчёты и два финальных кадра находятся в [qa/windows](../qa/windows).

Этот прогон проверяет Windows x64 и программный графический драйвер.
Физический геймпад, вывод звука, Smart App Control и производительность
конкретного пользовательского компьютера не измерялись.
