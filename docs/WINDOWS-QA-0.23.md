# Проверка Windows 0.23

Распакуйте самостоятельный архив целиком. Рядом должны находиться
BakuganPrototype-Windows.exe и BakuganPrototype-Windows.pck.
Запуск обычной игры: открыть EXE; интернет и редактор не нужны.

Встроенный сценарий из PowerShell в распакованной папке:

```powershell
.\BakuganPrototype-Windows.exe --script res://scripts/release_verifier.gd -- --verify-release
```

Диагностика работает с отдельным профилем diagnostics/0.23. Она запускает
шесть процессов: выигрыш, проигрыш, сохранение/продолжение броска кампании,
сохранение/продолжение посреди боя. Физика и правила определяют исход;
ввод выполняется через интерфейс. До каждой полной игры допускается
210 секунд. Общий отчёт summary.json должен иметь passed=true и один
run_id во всех стадиях.

Оба перезапуска сравнивают бинарный хеш позиции/скорости, RNG, камерного
слежения, мини-игры, эффектов и руки. Продолжение использует видимые
кнопки экрана слотов. Проверяется сохранение результатов и наград.

Windows-сервер GitHub использует ANGLE/WARP. Командные аргументы драйвера
передаются дочерним процессам. Игровой PCK и официальный EXE не меняются;
дополнительных графических DLL в игровой ZIP нет. Нативный запуск и
программная графика проверяют эту среду, а не производительность
пользовательской видеокарты.

Ручная проверка на ПК: новый профиль/перенос старого, обучение, все
категории слотов, отмена замены, пауза во время броска и мини-игры,
выход в меню, продолжение после закрытия процесса, звук и отключение
геймпада. Не запускайте автоматическую диагностику одновременно
с обычной игрой в том же экземпляре движка.

Окончательные результаты Windows добавляются к GitHub Release после
проверки фактически собранного ZIP.

Нативный прогон итогового ZIP завершён успешно на Windows-сервере GitHub
(Microsoft Windows 10.0.26100, ANGLE/WARP). Полные результаты: победа 3:2,
поражение 1:3, продолжение броска 3:1 и боя 3:0. Все шесть стадий имеют
один run_id; оба бинарных хеша после перезапуска совпали. Профиль,
результаты и награды сохранены. Проверки ресурсов, слотов и баланса
пройдены. [Отчёты Windows](https://github.com/tiiiiiiiiima/RBHETWN/tree/main/qa/windows-0.23).
Дочерние процессы используют автоматический переход на ANGLE;
предупреждение драйвера учтено, ошибок игрового кода не обнаружено.
