# Проверка Windows 0.24

До публикации готовый PCK и неизменённый официальный Godot 4.6.3
проверяются на Windows Server GitHub Actions (windows-2025, ANGLE/WARP).
Используются отдельные диагностические профили, исходники/ROM не нужны.

Проверки охватывают исходные ресурсы, новые броски/карты, слоты, прежние
исправления и измерение Scratch. Полные матчи запускаются обычными
событиями мыши/клавиш: победа, поражение, сохранение полёта и боя,
продолжение после перезапуска процесса, отдельный полный матч на Pyrus.
Состояния сохранения/продолжения сравниваются по двоичному SHA-256.

Итоговые отчёты публикуются вместе со сборкой в GitHub Releases.
Параметры производительности серверного WARP не описывают FPS на домашнем
ПК. Физический геймпад и прослушивание звука на Windows не подтверждены
серверным прогоном; игровая аудиосистема предыдущей версии сохранена.
