# Версия 0.22 — стабильность и диагностика

Скрытые человеческие аватары откладывают загрузку модели и прекращают
обработку костей. Закрытая боевая сцена прекращает фоновые анимации,
включая возвращение из паузы; открытый бой возобновляет исходные движения.
Каталог DS-арен удерживает не более 16 последних компонентов. Уже созданные
сцены сохраняют свои ресурсы после вытеснения из этого кеша.

Прогноз DS-траектории ограничен восемью обновлениями в секунду при изменении
прицела и зарядки. Сама физика броска, контакт с объектами и результаты
рассчитываются прежним движком с обычным шагом.

Закрытие при ошибке записи больше не теряет прогресс молча: игра предлагает
вернуться или явно выйти без сохранения. В аниме-колоде появились запись
через временный файл, резервная копия и восстановление из неё. Старые профили
и формат бинарного матча сохранены. Отключение геймпада отменяет зарядку
и удержание мини-игры; самопроизвольный бросок не создаётся.

В пакет входит проверочный сценарий без Python/редактора. Он играет полный
быстрый DS-матч, начинает кампанию, сохраняет движущуюся сферу, закрывает
процесс, продолжает матч новым процессом и проверяет запись результатов.
Ввод идёт через настоящий интерфейс; попадания, победители и очки не заданы.
Диагностика использует отдельную пользовательскую папку, не основной профиль.
Состояние генератора сохраняется в JSON строкой, а сравнение после перезапуска
использует SHA-256 исходных бинарных значений, без округления JSON.

Измеряются загрузка, кадры по фазам, p95/p99, память движка, объекты и
графический адаптер. Память движка не равна рабочему набору всего процесса; последний
снимается отдельно через доступный системный счётчик.

Проверки выполнены на Linux/Godot 4.6.3/llvmpipe и на настоящем
Windows-сервере GitHub (Microsoft Windows 10.0.26100), ANGLE/WARP.
На Windows проверены те же байты EXE/PCK/ZIP: 3098 ресурсов, 13280
утверждений и 69 проверок исправлений. Быстрый матч закончился 3:1,
кампания после перезапуска — 3:0. Бинарное состояние броска совпало,
результаты и награды пережили загрузку профиля. Журналы трёх процессов
не содержат ошибок или предупреждений.

Графический серверный прогон использовал внешний вариант встроенного
сценария: изменены только аргументы графического драйвера и путь сценария
для дочерних процессов. Игровой PCK, физика, ввод и проверки остались теми же.
Физический геймпад, вывод звука и FPS на игровой видеокарте требуют
проверки на устройстве. Протокол: WINDOWS-QA-0.22.md.
Измерения: PERFORMANCE-0.22.md.
