# Источники 0.21

Использован ранее предоставленный архив Bakugan Battle Brawlers DS.
Новых сторонних статичных аватаров не добавлено.

- Модели/текстуры: Game/Character/Character/chara00–16 и chara18,
  исходные NSBMD/NSBTX и собственные *_data.bin с BCA0-анимацией.
- Имена: font/mes_StoryCharaName.mes, индексы 0–16 и 18.
- Подсказки: font/mes_tips_Dan.mes и mes_Tutorial.mes. Порядок урока
  и объяснения по-русски написаны для интерфейса ПК.
- Импорт: apicula → embedded GLB. Материальные/visibility-каналы,
  которые конвертер не переносит, не выдаются за анимацию скелета.
- Полные исходные пути, SHA-256, список клипов и число каналов:
  assets/ds/avatars/manifest.json внутри PCK. 18 моделей прошли
  визуальную проверку и проверку реального изменения поз костей.
- Музыка: уже извлечённые SDAT SEQ_BGM_TUTORIAL / SEQ_BTL_BGM.
  Численные ADX темы не переименованы в якобы подтверждённые оригинальные события.
- Голоса: исходные AHX, английский суффикс 0. Проверены 326 файлов;
  распознавание речи — вспомогательный материал, не доказательство личности.
  Реплики vo3080 / vo3100 упоминают Leonidas / Vladitor;
  соответствующие ограничения команды и персонажа явно записаны в директоре.
  Для остальных автоматического назначения персонажей нет.

Сборка содержит преобразованные ресурсы и скрипты ПК, без ROM/BIOS
или исполняемого кода DS. Авторство оригинальных ресурсов не изменяется
при конверсии; сохраняются прежние provenance notices.
