# Источники и механики поля 0.24

Исходные названия и действия шести бросков прочитаны из
font/mes_myroom.mes, строки 22–33. Их SHA-256 и текст сохраняет
[манифест бросков](../assets/ds/special_shots.json).
Строка mes_tips_Dan.mes#10 подтверждает полный S и необходимый уровень,
но не его число. Уровень 3 в кампании — выбранный порог ПК, а не
восстановленный параметр DS. Свободный бой открывает броски сразу.

Тексты всех специальных карт 701–712 и исходные изображения находятся в
[каталоге DS](../assets/ds/source_cards.json). Их эффекты не включаются
в каталог 112 карт колоды, поскольку они собираются непосредственно на поле.
Модель ability_filed0 конвертирована из пользовательского DS-архива.
Сопоставление SetData type 3 с этой моделью выведено из названий/позиций,
оригинальный диспетчер предметов не восстановлен. Пул карт равномерный,
выбирается сохраняемым RNG; это распределение ПК.

| Карта | Действие и ограничение ПК |
| --- | --- |
| 701 Another Throw | Один дополнительный бросок текущего владельца после завершения действия; нужен доступный резерв. Новую карту ворот в этом дополнительном действии не ставят. |
| 702 Second Chance | Начинает текущий бросок заново с той же мощностью/направлением/стихийным эффектом; S повторно не тратится. Предметы и разрушения не возвращаются. |
| 703 Sleight of Hand | При попадании меняет ворота на выбранную карту своей руки; прежняя возвращается владельцу. Нет карты в руке — нет замены. |
| 704 Trickster | При попадании заменяет сферу первым доступным другим бакуганом команды; исходный остаётся в резерве. |
| 705 Early Victory | При попадании немедленно захватывает ворота; промах не приносит победу. |
| 706 Surprise Attack | После попадания переносит к случайному стоящему противнику и выбирает случайную мини-игру. Нет противника — обычная постановка. |
| 707 Road Trip | После попадания переносит на случайные существующие ворота. |
| 708 Invulnerable | Не даёт силовой атаке снизить оставшуюся силу ниже 1 G; не защищает от Quake/Lightning. |
| 709 All For One | Удваивает исходный сбор текущего броска, до +240 G. |
| 710 Fill'er Up | Заполняет S до 100; не активирует Special Shot автоматически. |
| 711 Subtraction | Убирает уже полученный сбор G у всех стоящих и текущей сферы; будущие предметы продолжают работать. |
| 712 Addition | Удваивает исходный сбор G стоящих и текущей сферы; повторная карта не умножает его ещё раз. |

Subterra/Haos убирают стоящих бакуганов, но не захватывают карты.
Darkus сохраняет защиту от удаления и Critical K.O.; Ventus и Invulnerable
защищают только от Critical K.O. Очередность при одновременном сборе карт
следует порядку предметов. Это выбранные правила исполнения ПК.
Время лавы 4 с: предупреждение 0–0,9, урон 0,9–2,4, затем безопасная фаза;
очаги смещены на id×0,17 с. Активная лава наносит 30 G при входе, Pyrus
защищён. Порог разрушения 7×масштаб поля и численная сила ускорителей,
поворота, отскоков/атак — параметры ПК. Исходное прохождение DS до Pyrus
не выполнено; поле импортировано из данных, а не восстановлено по видео.

Происхождение моделей/анимаций 0.23 сохранено: анимированные DS/DoC формы
имеют приоритет, статичные используются при отсутствии подходящей анимации.
Аниме-дуэль сохраняет прямую постановку без физического броска.
