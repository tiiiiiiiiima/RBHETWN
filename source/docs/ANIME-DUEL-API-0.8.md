# API карточной дуэли 0.8

`scripts/anime_duel_rules.gd` — независимый от отрисовки `RefCounted`.
`scripts/anime_card_catalog.gd` содержит 60 Attribute Gate Cards,
10 Command Gate Cards и двадцать поддерживаемых способностей из публичной базы Bloxugan.

Все изменяющие методы возвращают `Dictionary`: успешный результат содержит
`ok: true` и `event`, отклонённый — `ok: false`, `event: "invalid"` и `error`.
Ошибочная команда не расходует карту, существо или ход. `new_match` также
возвращает результат и проверяет параметры до замены текущего состояния.

## Состояние

- `phase`: `opening`, `turn`, `battle`, `finished`; `turn`, `winner` (-1/0/1).
- `teams[owner][index]`: `id`, `name`, `attribute`, исходное `g`, `base_g`,
  `current_g`, `ability_g`, `gate_effect_g`, `owner`, `index`, `slot`, `status`
  (`reserve`/`field`/`defeated`), `original_attribute`.
- `gates[slot]`: описание карты, `owner`, `card_id`, `revealed`, `nullified`,
  `bakugan` — участники с `owner`, `index` и теми же полями существа.
- `gate_hands`, `ability_hands`, `gate_decks`, `ability_decks`,
  `spent_gates`, `spent_abilities`, `defeated`: массивы по двум игрокам.
- `battle`: `slot`, `priority`, `passes`, `chain`; элементы цепочки содержат
  `serial`, `owner`, `card`, `cancelled` и `resolved`.
- `seed_value`, `turn_serial`, `placed_this_turn`, `acted_this_turn`.

## Команды

| Метод | Результат / назначение |
| --- | --- |
| `new_match(team0, team1, seed=1, gate_loadouts=[], ability_loadouts=[])` | Три существа на игрока; пустые loadouts означают проверенные стандартные наборы; иначе передаются два массива строковых ID (6 ворот, 10 способностей) |
| `legal_gate_slots()` | Свободные индексы 0–15; соседство не требуется |
| `available_units(owner)` | Индексы живых существ в резерве |
| `field_units(owner)` | Индексы существ на поле, доступных для отзыва в свой ход |
| `place_gate(owner, hand_index, slot)` | Начальная постановка или не более одной карты в обычный ход |
| `throw_unit(owner, unit_index, slot)` | Бросок расходует действие хода; попадание в пустые ворота → `stand`, в союзные → `stack`, во вражеские → `battle`, мимо ворот → `miss`; союзные стойки суммируются в общем бою |
| `recall_unit(owner, unit_index)` | Вернуть своё живое существо с поля в резерв; расходует действие броска и сбрасывает временные усиления |
| `finish_turn(owner)` | Передать ход и выполнить локальный добор; в ходе боя отклоняется |
| `open_gate(owner, caster_index=-1, target_index=-1)` | В бою владелец ворот с приоритетом раскрывает карту; Delta может использовать выбранное своё существо и выбранного противника; Peacemaker возвращает `battle_cancelled` |
| `can_open_gate(owner)` | `bool`: проверка раскрытия, включая запрет открывать в ответ на ожидающий nullify; ИИ использует её, чтобы не зациклиться на запрещённом действии |
| `can_play_ability(owner, hand_index, caster_index=-1, target_index=-1, target_owner=-1)` | `bool`: проверить приоритет, вид/стихию выбранного существа и законность выбранной цели без расхода |
| `ability_error(owner, hand_index, caster_index=-1, target_index=-1, target_owner=-1)` | Причина запрета либо пустая строка |
| `play_ability(owner, hand_index, caster_index=-1, target_index=-1, target_owner=-1)` | Поместить обычную карту в цепочку либо выполнить immediate-карту; сохранить выбранного участника/цель и передать приоритет |
| `ability_casters(owner, hand_index)` | Индексы совместимых участников текущего боя |
| `battle_units(owner)` | Все участники текущего боя со стороны игрока |
| `battle_unit_breakdown(owner, index)` | Отдельные `base`, `gate`, `ability`, `total` выбранного участника |
| `pass_response(owner)` | Передать приоритет; два паса разрешают непустую цепочку; ещё два паса без новой цепочки завершают бой |
| `battle_totals()` | Два полных значения G-Power |
| `battle_breakdown(owner)` | `base`, `gate`, `ability`, `total` плюс `raw_ability` и `raw_gate`; сумма учитывает нижнюю границу ноль; разрешённые Command-переносы/потери относятся к `gate`, а не к `ability` |

Energy Merge открывается автоматически при появлении противоположной стороны
и переносит 125 G с последнего участника первому. Hazard меняет стихии всех
участников. Positive/Negative Delta уменьшают G выбранного противника или
своего существа по напечатанной проверке стихии. Peacemaker прекращает бой,
возвращает всех живыми и оставляет открытые пустые ворота. Эти команды
исполняются один раз: последующая отмена ворот не откатывает уже разрешённый
перенос/смену стихии. Это локальное решение жизненного цикла эффектов.

Начальная фаза: игрок 0 ставит карту, затем игрок 1, затем начинается ход
игрока 0. В бою приоритет первым получает владелец ворот. Временные усиления
сохраняются на стоящем существе до возврата в резерв; все участники проигравшей
стороны недоступны до нового матча. При равенстве общих сумм обе стороны
возвращаются живыми. Стихия после Hazard восстанавливается при возврате или
поражении. Корреляция может выбрать союзника второй стихии и дать обоим +100 G;
прочие целевые способности выбирают противника. `target_owner=-1` означает
противника; при явном владельце цели обязательно передаётся её индекс.
Уменьшение/перенос G ограничен наличным G выбранной цели, не всей команды.
При разрешении отложенной способности повторно проверяются вид/стихия
участника и союзная цель корреляции. Потеря условия даёт `ability_failed`
без эффекта; сыгранная карта остаётся потраченной. Нецелевые усиления,
отмена и nullify не зависят от текущего выбора цели в интерфейсе. Использованные карты ворот могут снова попасть
в резерв ворот только при полностью пустом поле и отсутствии доступных
ворот, чтобы партия не зависала. Это собственное решение прототипа.

Состав 3/6/10 подтверждён индексированным руководством Bloxugan. Стартовая
рука 3/5, добор по одной карте каждого типа за свой последующий ход, сетка,
одна постановка, порядок реакции, победа после поражения
всех трёх противников являются явно выбранной адаптацией. Неизвестные GCP,
GPD и HSP не превращаются в выдуманные игровые расходы. Обоснование и
ограничения: [BLOXUGAN-COMPARISON-0.8.md](BLOXUGAN-COMPARISON-0.8.md).
