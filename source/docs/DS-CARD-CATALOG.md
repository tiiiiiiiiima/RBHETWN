# Каталог исходных карт DS

В 0.12 карточные параметры восстановлены отдельно от коллекции:
`res://assets/ds/playable_cards.json` хранит исходные ID и шесть G-значений
всех 212 лицевых карт. **26 ворот и 40 способностей** доступны для выбора
в отдельном профиле DS и имеют реализованные эффекты. Wii- и DS-каталоги
сохраняют разные числа и колоды. Подробности и исходные числовые примеры:
[ASSET-SOURCES-0.12.md](ASSET-SOURCES-0.12.md),
[DS-RULES-AUDIT-0.12.md](DS-RULES-AUDIT-0.12.md).

## Коллекция и перенос 0.11

В 0.11 окно «Все карты» предоставляет выбор источника **Nintendo DS**
или **Workshop**. Поиск, фильтры, просмотр полного лица и увеличение
относятся к выбранному каталогу. Коллекция сама по себе не добавляет новые
эффекты в колоду; исполнимое подмножество 0.12 выбирается через профиль DS.

Источник — пользовательский DS-архив `B6RE`. `tools/decode_ds_ui.py`
получил исходные лица из NCG/NCL/NCE, а `tools/build_ds_card_catalog.py`
объединил уже декодированные изображения с английскими таблицами
`font/mes_CardName.mes` и `font/mes_CardText.mes`.
Данные находятся внутри PCK в `res://assets/ds/source_cards.json`.

| Тип | Количество |
| --- | ---: |
| Gold — ворота | 39 |
| Silver — ворота | 32 |
| Copper — ворота | 32 |
| Red — способности | 32 |
| Green — способности | 32 |
| Blue — способности | 33 |
| Специальные карты поля | 12 |
| Всего лицевых изображений | 212 |

Оборот `card_l_000` хранится отдельно и не считается новой картой.
Все лица имеют исходный размер **96×128**; увеличение не дорисовывает
детали. Хеши PNG сверяются с UI-манифестом. Имена и тексты сопоставлены
по возрастающим числовым идентификаторам изображений с 213 записями MES,
включая оборот. При выпуске 0.11 связь с параметрами карточного движка ROM
ещё не была разобрана; этот предел сохраняется в метаданных того каталога.
В 0.12 отдельная таблица native ID подтверждает порядок всех 213 индексов.

**180 карт** имеют декодированный исходный английский текст.
У **32 серебряных ворот** запись содержит только управляющий маркер
`0xff85`: описание остаётся пустым, а оригинальные коды записаны
в каталоге. Маркер не выдаётся за эффект и не заменяется выдуманным текстом.
В 0.11 числовые бонусы ворот и параметры способностей ещё не были
восстановлены; в 0.12 они сохранены отдельным числовым манифестом.

## Графика прежнего классического каталога Wii

Следующие совпадения используются в `CardArt` для оформления существующих
классических карт. Родное лицо DS содержит иллюстрацию, рамку и имя;
действующее правило и числа показываются интерфейсом прототипа отдельно.

| Игровая карта | Исходный идентификатор DS |
| --- | ---: |
| Dragonoid | 101 |
| Leonidas | 136 |
| Griffon | 125 |
| Aquos Vortex | 217 |
| The Cliffs | 220 |
| Sunrise | 215 |
| Stand Your Ground | 306 |
| Boosted Dragon | 511 |
| Mega Impact | 516 |
| Alpha Blaster | 527 |

Это **семь ворот и три способности**. У первых трёх персонажных ворот
совпадает текст об удвоении бонуса; у Stand Your Ground — возвращение
способностей; у трёх способностей — персонаж и +200 G. У трёх серебряных
ворот совпадает исходное имя и отсутствует расшифрованное числовое правило.
Эти сопоставления 0.11 сами по себе не подтверждают таблицу DS-бонусов.
В профиле Wii действующие правила продолжают использовать
проверенный консольный каталог [WII-SOURCES.md](WII-SOURCES.md).

В 0.12 карты, исключённые из исполняемого подмножества, остаются коллекцией.
Это специальные карты поля и эффекты, требующие ещё не реализованных
DS-мини-игр, а также остальные неподдержанные условия. Прежние 636 лицевых
изображений Workshop сохранены отдельно; переход между источниками
просмотра не меняет выбранную классическую или аниме-колоду.
Происхождение и ограничения:
[ASSET-SOURCES-0.11.md](ASSET-SOURCES-0.11.md).
