# Код Bakugan Arena 0.23

Скрипты, сцены, конфигурация, инструменты и тесты текущей версии.
Большие преобразованные ресурсы assets и кеш импорта .godot здесь
не размещены. Эти файлы позволяют изучать изменения, но для пересборки
нужен соответствующий рабочий каталог ресурсов. В готовом игровом
архиве ресурсы уже включены в PCK.

Для игры скачайте Bakugan-0.23-Windows.zip из Releases, распакуйте
целиком и откройте EXE. Автоматический GitHub Source code ZIP
не является самостоятельной игрой.

ROM/BIOS и исходный исполняемый код DS не размещены. Источники
преобразованных ресурсов и лицензии описаны в документации.
