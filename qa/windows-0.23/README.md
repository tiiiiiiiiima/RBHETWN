Дочерние процессы предупреждают об автоматическом переходе с
неподдерживаемого native OpenGL на ANGLE. Ошибок игрового кода
в журналах этих процессов нет. Измерения относятся к серверу с
программной графикой; физический геймпад, звук на устройстве и FPS
пользовательской видеокарты не проверены.
