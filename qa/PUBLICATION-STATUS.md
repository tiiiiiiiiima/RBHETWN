# Состояние 0.22

Игровой пакет и самостоятельный Windows ZIP собраны и проверены на Linux.
Отчёты находятся в [linux](linux). Нативный Windows-прогон ещё не выполнен.

Прямая загрузка в GitHub Releases вернула `401 Bad credentials` на
`uploads.github.com`; доступ к API и репозиторию работает. Черновик выпуска
подготовлен, игровых Assets в нём пока нет.

Альтернативная передача через отдельную временную ветку требует разрешения:
около 2 ГБ Git-объектов могут оставаться на сервере после удаления ветки.
Автоматическая проверка разрешений отклонила её до начала отправки;
объекты архива и временная ветка не созданы.

После разрешённой передачи workflow Assemble approved release transfer
проверяет точный SHA-256 ZIP и размещает его в черновике Releases. Затем
Windows 0.22 verification проверяет официальный EXE и игровой PCK,
3098 ресурсов, 69 утверждений и три настоящих процесса матча. Программная
OpenGL Mesa устанавливается только на временном runner, в ZIP она не входит.
При успехе workflow приложит результаты и опубликует выпуск.

После подтверждения игровых Assets временная ветка будет удалена.
