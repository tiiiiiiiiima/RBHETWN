# Bakugan Arena — 0.24

Стихийные броски и карты поля DS: шесть Special Shots с отдельными
эффектами, все 12 карт-предметов и предупреждение лавы на Pyrus.
Новые эффекты сохраняются вместе с незавершённым матчем; отдельные
слоты и прямое размещение в аниме-дуэли из прошлых выпусков сохранены.

Сборка 0.24 проходит окончательную проверку на Windows.
[Опубликованные выпуски](https://github.com/tiiiiiiiiima/RBHETWN/releases).

[Изменения](source/docs/RELEASE-0.24.md) · [Источники и правила](source/docs/DS-FIELD-0.24.md) · [Проверка Windows](source/docs/WINDOWS-QA-0.24.md) · [Код](source)

Готовая игра находится в **Releases → Assets → Bakugan-…-Windows.zip**.
Распакуйте ZIP целиком, откройте **BakuganPrototype-Windows.exe**
и оставьте одноимённый `.pck` рядом. Движок и ресурсы включены;
интернет при запуске не нужен. Нужны Windows x64 и OpenGL 3.3.

Автоматический Source code ZIP содержит скрипты и документацию;
большие игровые ресурсы находятся в игровом ZIP из Releases.
Численная физика, порог открытия бросков и распределение карт — адаптация ПК;
полное совпадение с DS/Wii не заявляется.
