# Bakugan Arena — 0.22

[Скачать Windows ZIP](https://github.com/tiiiiiiiiima/RBHETWN/releases/download/v0.22.0/Bakugan-0.22-Windows.zip) · [Все выпуски](https://github.com/tiiiiiiiiima/RBHETWN/releases)

Распакуйте архив целиком и откройте **BakuganPrototype-Windows.exe**. Оставьте одноимённый `.pck` рядом. Движок и игровые ресурсы включены; интернет при запуске не нужен. Нужны Windows x64 и OpenGL 3.3.

Версия 0.22 исправляет обработку ошибок сохранения, отмену зарядки при отключении геймпада и лишнюю работу скрытых анимаций. Ограничены кеш арен и частота прогноза траектории. Сама физика продолжает обновляться с обычным шагом.

[Изменения](docs/RELEASE-0.22.md) · [Проверка на Windows](docs/WINDOWS-QA-0.22.md) · [Измерения](docs/PERFORMANCE-0.22.md)

Готовая игра находится в **Releases → Assets**. ZIP исходников, автоматически создаваемый GitHub, содержит только эту страницу, документацию и диагностику. Полный игровой архив называется `Bakugan-0.22-Windows.zip` (около 1.89 ГиБ).

Контрольная сумма SHA-256 публикуется рядом с архивом. Результаты проверки находятся в разделе `qa`; измерения программной графики не описывают FPS на игровой видеокарте. Физический геймпад пока не проверен.
